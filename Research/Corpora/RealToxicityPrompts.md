# RealToxicityPrompts

RealToxicityPrompts attests a prompt, a continuation, and scores that are lineage of the Perspective API.

The composition is a prompt and its continuation. The mask is the score. The value is the score. Witness RealToxicityPrompts. Lineage is the Perspective API, because the dataset card says the scores were generated by that API. The scores are not an independent witness of toxicity. They are the API's output stored again. Deviation 90, the recipe's choice. The recipe reads the refresh drop. There is no live directory.

A score on a prompt does not attest the sense or the dependency role of a token. Using the score as if annotators had assigned it erases the lineage. Fanout does not multiply just because the continuation is long. The score is one value on the pair.

## Files, breakdown, and caveats

Taken from the recipe files. A line in a block is a directive. The prose above it is that file's own account of what is read, what is not, and what a row becomes.

### `real-toxicity-prompts/prompts.recipe`

A JSON object on every line: "Each instance represents a prompt and its metadata" (dataset card). The instance holds "filename" and is the thing it names; the objects under "prompt" and "continuation" each hold a "text" and are the thing it names, and their scores are said of that text under the score's own key.

```text
match prompts.jsonl
grammar json
records
identity * filename
identity * text
```

### `real-toxicity-prompts/source`

RealToxicityPrompts: sentence snippets from the web, each split into a prompt and a continuation, with scores. The dataset card's title: "Dataset Card for Real Toxicity Prompts"; its summary names it RealToxicityPrompts. The dataset card: "The scores accompanying the prompt and the continuation are generated using the Perspective API". The deviation is this recipe's choice for a curated academic resource; the specification does not give one.

```text
witness RealToxicityPrompts
lineage Perspective API
deviation 90
root $LAPLACE_DATA/.refresh-*/Safety/RealToxicityPrompts/real-toxicity-prompts-*[0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f][0-9a-f]
reads text
```
