# Corpora

The collections at `/vault/Data`, `/vault/Data/.refresh-20260903`, and `/vault/models` are the files Laplace ingests.

Where each collection sits is [Corpus layout](Layout.md). What a curated file attests is [Attestations](../../Semantics/Attestations.md). The mask and the value are [Claims](../../Semantics/Claims.md). A hop from one collection to another is [Pull](../../Semantics/Pull.md).
