# Engineering

The engineering standard and the architecture boundaries bind every implementation choice in every active repository.

- [Laplace engineering standards](Standards.md): end-to-end execution, one semantic implementation, compositional scalars, deterministic SIMD dispatch, lawful memoization, recipes, PostgreSQL set probes, in-place reconcile, live-server verification, and batch discipline.
- [Architecture boundaries](Boundaries.md): authority flow, the pure C17 `Laplace-Native` core, the client-determinism vs. in-database C split, `Laplace-Engine` and `Laplace-MCP`, thin C# product orchestration, and generated contracts.
