## Format

| Record | Fields in order | What a record is | Proof |
| --- | --- | --- | --- |
| frame | definition, semType, FE, FEcoreSet, frameRelation, lexUnit; attributes ID, name, cDate, cBy | A frame file's root element. The schema comment at the top of frame.xsd is older than the element sequence; the sequence here is the xsd:sequence. | `/vault/Data/FrameNet/framenet_v17/schema/frame.xsd` |
| FE | definition, semType, requiresFE, excludesFE; attributes ID, name, abbrev, cDate, cBy, coreType, fgColor, bgColor | A frame element inside a frame. | `/vault/Data/FrameNet/framenet_v17/schema/frame.xsd` |
| lexUnit in a frame | definition, sentenceCount (total, annotated), lexeme, semType; attributes ID, name, POS, incorporatedFE, status, cDate, cBy, lemmaID | A lexical unit embedded in a frame file. | `/vault/Data/FrameNet/framenet_v17/schema/frame.xsd`; `/vault/Data/FrameNet/framenet_v17/schema/commonTypes.xsd` basicLUAttributes |
| lexUnit file | header, definition, lexeme, semType, valences, subCorpus; attributes ID, name, POS, incorporatedFE, status, frameID, frame, totalAnnotated | A standalone lexical-unit file, the format adopted as of R1.4. | `/vault/Data/FrameNet/framenet_v17/schema/lexUnit.xsd` |
| lexeme | attributes name, POS, breakBefore, headword, order | An attributes-only element on a lexical unit. | `/vault/Data/FrameNet/framenet_v17/schema/commonTypes.xsd` |
| sentence | text, annotationSet; attributes ID, aPos, paragNo, sentNo, docID, corpID, externalID | A sentence and its annotation sets. | `/vault/Data/FrameNet/framenet_v17/schema/sentence.xsd` |
| annotationSet | layer; attributes ID, status, frameName, frameID, luName, luID, cxnName, cxnID, cDate | One annotation of a sentence. | `/vault/Data/FrameNet/framenet_v17/schema/sentence.xsd` |
| layer | label; attributes name, rank | A named layer of labels inside an annotation set. | `/vault/Data/FrameNet/framenet_v17/schema/sentence.xsd` |
| label | attributes name, start, end, fgColor, bgColor, itype, feID, cBy | One label on a layer. itype is APos, CNI, INI, DNI, or INC. | `/vault/Data/FrameNet/framenet_v17/schema/sentence.xsd` |
| fullTextAnnotation | header, sentence | A full-text document. The sentence element has the same structure as in lexicographic annotation. | `/vault/Data/FrameNet/framenet_v17/schema/fullText.xsd` |
| frameRelations | frameRelationType (ID, name, superFrameName, subFrameName), containing frameRelation (ID, superFrameName, subFrameName, supID, subID), containing FERelation (ID, superFEName, subFEName, supID, subID); root attribute XMLCreated | The frame-to-frame relation file. | `/vault/Data/FrameNet/framenet_v17/schema/frameRelations.xsd`; `/vault/Data/FrameNet/framenet_v17/frRelation.xml` |
| semTypes | semType (definition, superType with superTypeName and supID; attributes ID, name, abbrev); root attribute XMLCreated | The semantic-type file. | `/vault/Data/FrameNet/framenet_v17/schema/semTypes.xsd` |
