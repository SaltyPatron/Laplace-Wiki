# Wordnets

The wordnets attest sense, and CILI is the hop that changes language without becoming a second witness of the Princeton gloss.

## Format

| Record | Field | Order | Type | Specification |
| --- | --- | --- | --- | --- |
| `data.`*pos* preamble | line | before the data lines | text | "Each data file begins with several lines containing a copyright notice, version number and license agreement. | `data.`*pos* line | `synset_offset` | 1 | 8 digit decimal integer | "Current byte offset in the file represented as an 8 digit decimal integer."
