# Wiktionary

Wiktextract attests a written word in one language as one part of speech, and every edition of that extract is the same witness.

| word entry | No order fixed. The README lists word, pos, lang, lang_code, senses, forms, sounds, categories, topics, translations, etymology_text, etymology_links, etymology_templates, etymology_number, descendants, synonyms, antonyms, hypernyms, holonyms, meronyms, derived, related, coordinate_terms, wikidata, wiktionary, head_templates, inflection_templates, and says others may also be present. | One JSON object per line: a written word in one language as one part of speech. A redirect object is the other shape. | [Wiktextract README, Format of the extracted word entries](https://github.com/tatuylonen/wiktextract/blob/master/README.md) |
| redirect | redirect, title | A redirect entry. It does not have pos. Redirects are not associated with a language. | [Wiktextract README, Format of extracted redirects](https://github.com/tatuylonen/wiktextract/blob/master/README.md) |
| sense | No order fixed. Keys listed under Word senses, including glosses. | One dictionary in the senses list. | [Wiktextract README, Format of the extracted word entries](https://github.com/tatuylonen/wiktextract/blob/master/README.md) |
| form | form, tags, and optionally ipa, roman, source | One dictionary in the forms list. | [Wiktextract README, Format of the extracted word entries](https://github.com/tatuylonen/wiktextract/blob/master/README.md) |
| translation | No order fixed. Keys listed under Translations: alt, code, english, lang, note, roman, sense, tags, taxonomic, word. | One translation dictionary, on the entry or on a sense. | [Wiktextract README, Format of the extracted word entries](https://github.com/tatuylonen/wiktextract/blob/master/README.md) |
