# OpenSubtitles

OpenSubtitles attests the language of a subtitle sentence and does not attest the language of a word.

## Format

| Record | Field | Order | Type | Specification |
| --- | --- | --- | --- | --- |
| native XML sentence | id | 1, on `s` | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> | Sentences are numbered with unique IDs, unique within the XML file and not within the corpus. The page shows `id="1"` and gives no schema type. These IDs are what sentence alignment uses. |
| native XML sentence | text | 2, character data of `s` | text | Raw files add sentence boundaries. The page says only sentence boundaries are added there, plus possible document markup such as paragraph boundaries. The amount of markup varies by corpus and language. |
| language mark | directory | path, not a column of `s` | language ID | Corpus files are stored in sub-directories named by the language ID, using 2-letter ISO-639 language codes as much as possible. Aligned documents share a path relative to that directory. |
| language mark | Moses file extension | the extension of each bitext file | language ID | A plain-text bitext is two files whose corresponding lines are aligned. The name uses file extensions that correspond to the language ID. The page's example is `RF.en-fr.en` and `RF.en-fr.fr`. |
| language mark | xml:lang | attribute of `tuv` | language ID | A TMX bitext sets `header segtype="sentence"`. Each `tu` holds one `tuv` per language. `xml:lang` is on `tuv`. The sentence is the text of `seg`. |
| language mark | LANGUAGE | attribute of `SPEAKER` in the Europarl example | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> | The native-XML example puts `LANGUAGE="DE"` on `SPEAKER` around English sentence text. The page does not define that attribute as the language of `s`, and it does not put a language on `s` or on `w`. |
| sentence alignment | fromDoc | attribute of `linkGrp` | path | Source-language file, relative to the xml directory of the corpus. `linkGrp` has `targType="s"`. The same sentence boundaries are used for the raw and tokenized files. |
| sentence alignment | toDoc | attribute of `linkGrp` | path | Target-language file, relative to the xml directory. Alignments are stored in one direction, with language IDs sorted alphabetically in the alignment file name. |
| sentence alignment | xtargets | attribute of `link` | sentence IDs | The two sides are separated by `;`. Several IDs on one side are separated by whitespace. Either side may name any number of sentences, including none. |
| sentence alignment | certainty | attribute of `link`, when present | Not defined as a probability. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> | The page says the certainty is not a likelihood in terms of proper probabilities. The value is copied from the alignment tool. |
| Moses bitext | line | line number, paired across the two files | UTF-8 text | The files are untokenized. One line may hold several sentences when those sentences are aligned together. Empty alignments are excluded. Every plain-text file is Unicode UTF-8. A monolingual file puts each sentence on its own line. |
| tokenized XML | w | child of `s` in the tokenized files | element | Tokenized files add token boundaries with `w`. The page says additional annotation may be included, and its `pos` and `lem` example is Europarl. Markup varies. No field on `w` is defined as the language of the word. |

## Value

| Field | Composition | Mask | What is recorded | Lineage or hop | Specification |
| --- | --- | --- | --- | --- | --- |
| id | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The identifier of one sentence inside one XML file. | The identifier is an endpoint of a sentence alignment. | [Attestations](../Semantics/Attestations.md) uses a sentence from OpenSubtitles as the example of a language attestation, and says the attestation is recorded at the highest tier the corpus supports. |
| text | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The subtitle sentence. The language attestation lands on this sentence. | None on the text itself. | [Attestations](../Semantics/Attestations.md) says a sentence from OpenSubtitles is attested to be English, or whichever language it is, and that OpenSubtitles gives the language of sentences, not of words. |
| directory | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The language of each sentence stored under that directory. The mark does not land on a word. | The directory is the language of the sentence file. | Language IDs are the directory names on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Attestations](../Semantics/Attestations.md). |
| Moses file extension | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The language of the line. A bitext line is one sentence or several sentences aligned together. | A paired line is a sentence-to-sentence hop. | Plain text on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Pull](../Semantics/Pull.md#hop-and-fanout) is the hop. |
| xml:lang | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The language of the `seg` in that `tuv`. The mark is on the sentence container, not on a word. | The two `tuv` elements of one `tu` are a sentence-to-sentence hop. | TMX on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Pull](../Semantics/Pull.md#hop-and-fanout). |
| LANGUAGE | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> The example attribute is on `SPEAKER`. It is not the language attestation of the sentence, and it is not the language of a word. | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> | The language attestation remains the sentence language in [Attestations](../Semantics/Attestations.md). |
| fromDoc | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The file of the source sentences named by `xtargets`. | The file is one side of a sentence-to-sentence hop. | XCES `cesAlign` on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Pull](../Semantics/Pull.md#hop-and-fanout). |
| toDoc | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The file of the target sentences named by `xtargets`. | The file is the other side of a sentence-to-sentence hop. | XCES `cesAlign` on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Pull](../Semantics/Pull.md#hop-and-fanout). |
| xtargets | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The sentence IDs on each side of one alignment. | A hop from a sentence to the sentence or sentences on the other side of `;`. | XCES `cesAlign` on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> A paired translation is a sentence-to-sentence hop. [Pull](../Semantics/Pull.md#hop-and-fanout). |
| certainty | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The alignment tool's score, copied onto the link. The page says it is not a probability. | It is attached to the sentence-to-sentence link. | Not defined as a probability. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> |
| line | sentence | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | The aligned plain text. Its language is the file extension. The line may contain more than one sentence. | The same line number in the other file is a sentence-to-sentence hop. | Plain text on <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html.> [Attestations](../Semantics/Attestations.md). [Pull](../Semantics/Pull.md#hop-and-fanout). |
| w | word | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> does not define a part-of-speech, sense, or dependency mask. | A token boundary inside the sentence. The language of a word is not recorded. | Not defined. <https://opus.nlpl.eu/legacy/trac/wiki/DataFormats.html> | [Attestations](../Semantics/Attestations.md) says OpenSubtitles gives the language of sentences, not of words. `pos` and `lem` in the Europarl example are not that language mark. |
