# Tokenizers

A model tokenizer's vocabulary is observed content and attests nothing.

## Format

| Record | Field | Order | Type | Specification |
| --- | --- | --- | --- | --- |
| vocab.json | token | JSON object key | string | The GPT-2 page says vocab is a dict from string to int, a custom vocabulary dictionary loaded from vocab_file when omitted. The BERT page says the same for vocab, loaded from vocab_file. BertTokenizerLegacy calls vocab_file the file containing the vocabulary. The Qwen2 page types vocab as str, dict from string to int, or None, and does not describe the file. Key order inside the JSON object is Not defined. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/bert> <https://huggingface.co/docs/transformers/model_doc/qwen2> |
| vocab.json | id | JSON object value of that token | int | The GPT-2 and BERT pages type the vocabulary dictionary as a dict from string to int. The integer is the id of the token string. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/bert> |
| merges.txt | merge | one element of the merges list | string | The GPT-2 page says merges is a str or a list of str, a custom merges list loaded from merges_file when omitted. The Qwen2 page types merges as str, list of str, or None, and does not describe the file. How one string divides into the two pieces of a pair is Not defined. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/qwen2> The components page says BPE merges the pair most frequently seen together and does not give the file grammar. <https://huggingface.co/docs/tokenizers/components> |
| tokenizer.json | model.vocab | vocabulary object inside model | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | Tokenizer.from_file loads tokenizer.json. The pipeline page says the model maps tokens to their IDs in the vocabulary. The models page names BPE, Unigram, WordLevel, and WordPiece and does not define the JSON object. <https://huggingface.co/docs/tokenizers/pipeline> <https://huggingface.co/docs/tokenizers/api/models> |
| tokenizer.json | model.merges | merge list inside model, for a model that has one | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | GPT-2 and Qwen2 take a merges list. The BERT page is WordPiece, names a vocabulary, and does not name a merges file. The models page does not say which model type stores a merges list, or that each merge is a string. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/qwen2> <https://huggingface.co/docs/transformers/model_doc/bert> <https://huggingface.co/docs/tokenizers/api/models> |
| tokenizer.json | model.type | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | The pipeline and models pages name models.BPE, models.Unigram, models.WordLevel, and models.WordPiece. They do not define a JSON key for that name. <https://huggingface.co/docs/tokenizers/pipeline> <https://huggingface.co/docs/tokenizers/api/models> |
| tokenizer.json | added token | one object in added_tokens | Not defined. <https://huggingface.co/docs/tokenizers/api/added-tokens> | The Added Tokens page names the attributes content, lstrip, normalized, rstrip, and single_word, and does not define their types. id and special are Not defined. <https://huggingface.co/docs/tokenizers/api/added-tokens> |

## Value

| Field | Composition | Mask | What is recorded | Lineage or hop | Specification |
| --- | --- | --- | --- | --- | --- |
| token | observed token string | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | Observed content. The first paragraph says a model tokenizer's vocabulary is observed content and attests nothing. | [Models](../Research/Models.md) says every tokenizer was ingested as content, that each tokenizer's tokens were decomposed like any text, and that the vocabulary became the path of its tokens in index order. | [Attestations](../Semantics/Attestations.md) says normal digital content does not give attestations and gives observations. The string is not a sense witness. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/bert> |
| id | index of that token on the vocabulary path | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | The integer id of an observed token string. The id attests nothing about a sense. | Index order is the path in [Models](../Research/Models.md). It is not a hop to a sense. | The GPT-2 page types the vocabulary value as int. <https://huggingface.co/docs/transformers/model_doc/gpt2> <https://huggingface.co/docs/transformers/model_doc/bert.> |
| merge | observed merge string | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | One string from the merges list. It is observed content and attests nothing. | Not defined. <https://huggingface.co/docs/transformers/model_doc/gpt2> The components page describes a BPE pair and does not define a hop. | <https://huggingface.co/docs/tokenizers/components> says BPE merges the most frequent pair. The string is not a sense witness. [Attestations](../Semantics/Attestations.md) says normal digital content does not give attestations and gives observations. |
| model.vocab | observed vocabulary | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | The same kind of token-to-id record as vocab.json, carried inside tokenizer.json. Observed content. | The path of tokens in index order, from [Models](../Research/Models.md). | Not defined as a JSON schema. <https://huggingface.co/docs/tokenizers/api/models> <https://huggingface.co/docs/tokenizers/pipeline> |
| model.merges | observed merge list | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | The merges stored on a model that has them. A WordPiece vocabulary is still observed content when no merges list is defined for it. | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | The BERT page does not name merges. <https://huggingface.co/docs/transformers/model_doc/bert> <https://huggingface.co/docs/tokenizers/api/models> |
| model.type | the named model algorithm | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | Not defined. <https://huggingface.co/docs/tokenizers/api/models> The pages name BPE, Unigram, WordLevel, and WordPiece. The name is not a sense. | Not defined. <https://huggingface.co/docs/tokenizers/api/models> | <https://huggingface.co/docs/tokenizers/pipeline> <https://huggingface.co/docs/tokenizers/components> |
| added token | observed token string | Not defined. <https://huggingface.co/docs/tokenizers/api/models> does not define a part-of-speech, sense, or dependency mask. A string in a vocabulary is not a sense witness. | The content attribute is another observed string in the tokenizer file. It is not a sense witness. id and special are Not defined. <https://huggingface.co/docs/tokenizers/api/added-tokens> | Not defined. <https://huggingface.co/docs/tokenizers/api/added-tokens> | <https://huggingface.co/docs/tokenizers/api/added-tokens> [Attestations](../Semantics/Attestations.md) says normal digital content does not give attestations and gives observations. |
