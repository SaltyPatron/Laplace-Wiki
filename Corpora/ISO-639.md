# ISO 639

ISO 639 attests the identity of a language, which is the value other corpora use when they name a language.

## Value

| Field | Composition | Mask | What is recorded | Lineage or hop | Specification |
| --- | --- | --- | --- | --- | --- |
| `Id`, `madsrdf:code`, alpha-3 (bibliographic), alpha-2, `Part1` | The code is one entity in a claim tuple. [Claims](../Semantics/Claims.md#tuples) | Not named in [Claims](../Semantics/Claims.md#masks). | The identity of a language. A curated corpus attests that identity of the content it states, at the highest tier that corpus states. [Attestations](../Semantics/Attestations.md#attestations) | The registration agency is the witness. A second table that repeats the same code is not a second witness. [Attestations](../Semantics/Attestations.md#witnesses). Not a hop [Pull](../Semantics/Pull.md#hop-and-fanout) defines. | [Attestations](../Semantics/Attestations.md#attestations), [Attestations](../Semantics/Attestations.md#witnesses), [Claims](../Semantics/Claims.md#tuples) |
| alpha-3 (terminologic), `Part2b`, `Part2t` | The same language entity under the other identifier set. [Claims](../Semantics/Claims.md#tuples) | Not named in [Claims](../Semantics/Claims.md#masks). | The same language, when the publisher gives the equivalent code. | Not an independent witness of that language. [Attestations](../Semantics/Attestations.md#witnesses) | [Attestations](../Semantics/Attestations.md#witnesses) |
| English name, French name, German name, `Ref_Name`, `Print_Name`, `Inverted_Name` | A name of the language entity, not a second entity. [Claims](../Semantics/Claims.md#tuples) | Not named in [Claims](../Semantics/Claims.md#masks). | A name the publisher associates with the identifier. `Ref_Name` is not preferred over the names index. | Not a second witness of the language. [Attestations](../Semantics/Attestations.md#witnesses) | [Attestations](../Semantics/Attestations.md#witnesses) |
| `Scope`, `Language_Type` | A qualifier on the same language entity. | Not named in [Claims](../Semantics/Claims.md#masks). | Individual, macrolanguage, or special; and the publisher's type code. | Not a hop. | [Attestations](../Semantics/Attestations.md#attestations) |
| `Comment` | Text on one or more columns of the same row. | Not named in [Claims](../Semantics/Claims.md#masks). | The publisher's comment. The opened non-empty comment says the 639-1 element `sh` is deprecated. | Not a second witness. | [Attestations](../Semantics/Attestations.md#witnesses) |
| `M_Id`, `I_Id`, `I_Status` | Two language entities in one claim tuple, plus the status of the individual code. [Claims](../Semantics/Claims.md#the-linguistic-super-highway) | [Claims](../Semantics/Claims.md#tuples) |
| `Ret_Reason`, `Change_To`, `Ret_Remedy`, `Effective` | The retired identifier and, for C, D, and M, the identifier it changes to. [Claims](../Semantics/Claims.md#tuples) | Not named in [Claims](../Semantics/Claims.md#masks). | The publisher's retirement of a code. The code is not a second living identifier. | Lineage of the code, not a second witness of the language. [Attestations](../Semantics/Attestations.md#witnesses) | [Attestations](../Semantics/Attestations.md#witnesses) |
| ISO 639-5 Identifier, English name, French name | A language-family or language-group entity. [Claims](../Semantics/Claims.md#tuples) | Not named in [Claims](../Semantics/Claims.md#masks). | The identity of a family or group, which is still a language code other corpora can name. | The Language Coding Agency is the witness. The opened RDF is a partial copy of that list, not a second witness. [Attestations](../Semantics/Attestations.md#witnesses) | [Attestations](../Semantics/Attestations.md#witnesses) |
| Hierarchy | The path of family identifiers the publisher writes. | Not named in [Claims](../Semantics/Claims.md#masks). | Which other family or group the publisher says this one is a member of. | Not a hop [Pull](../Semantics/Pull.md#hop-and-fanout) defines. The column is not in the opened RDF. | [Pull](../Semantics/Pull.md#hop-and-fanout) |
| 639-2, Notes | Not defined by a sentence on the pages opened. | Not named in [Claims](../Semantics/Claims.md#masks). | Not defined. Opened [Identifiers](https://www.loc.gov/standards/iso639-5/id.php) and `/vault/Data/ISO639/loc/iso639-5.rdf`. | Not a hop. | Not defined. [Identifiers](https://www.loc.gov/standards/iso639-5/id.php) |
