## Format

| Record | Fields in order | What a record is | Proof |
| --- | --- | --- | --- |
| frameset | note or predicate, any number | The root of a frame file. Each file contains predicates associated with a lemma. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| predicate | note or roleset, any number; attribute lemma | A predicate for one lemma, including phrasal variants. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| roleset | aliases, note, roles, usagenotes, then lexlinks or example or note; attributes id, name | One sense of a predicate, with argument-label mnemonics and examples. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| alias | text; attribute pos (r, p, v, n, j, l, x, m, d, f) | An alias of the roleset. The comment glosses r, p, v, n, j, l, x, and m, and does not gloss d or f. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| role | rolelinks; attributes n (0, 1, 2, 3, 4, 5, 6, 7, m, M), f, descr | One role in a roleset. n is a number or M for adjuncts. f is a function tag. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| example | note, text, then propbank or amr or note; attributes name, src | An example sentence for a roleset. In v3.4 the argument structure sits under propbank. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| arg | text; attributes type, start, end | A span in an example. type enumerates ARG0-ARG7, C-ARG0-C-ARG7, R-ARG0-R-ARG7, and ARGM- forms. | `/vault/Data/PropBank/propbank-frames-main/dtds/v3.4/frameset.dtd` |
| rel | text; attribute relloc | The relation target in an example. | frames/frameset.dtd role and example | role n is 0, 1, 2, 3, 4, 5, 6, 7, m, M and f is a shorter list; example is note, text, then arg or rel or note; arg attributes n (including a and A), f, start, end | The frameset DTD copied under frames/.
