# VerbAtlas

VerbAtlas attests what each of its eleven tab-separated files says of a frame, a selectional preference, a BabelNet synset, a WordNet synset, or a PropBank predicate sense, under the names its README gives the columns, and its README and licence lines attest nothing.

One source reads VerbAtlas 1.1.0, "WordNet synsets clustered into frames, with the mappings the package ships beside them". Every file is a tab-separated table without a header row, read by a recipe of its own. Where the README names a column, that name is the predicate, as the README writes it, through a `predicate` or an `attest` line of the recipe; the names after `columns` in a recipe "only point at a position in the row and are never recorded". Where the README names nothing, the row is a pair or a tuple in the row's own order. VerbAtlas is a hop between lexicons, as [Hops](Hops.md) lists it.

| every file | an empty field | what the file leaves empty: attests nothing | none | |

A claim from a file without `together` is a record of its own, witnessed once. Nothing is renamed, reordered, or filled in: the predicate `VerbAtlas frame ID` is the README's phrase, spaces and all, and the argument structure of `VA_frame_pas.tsv` is the row itself because the README names no role.

## Not read

The first line of each `VA_*.tsv` file is a licence line, "VerbAtlas 1.1.0 - SapienzaNLP - LICENSE: ...", and the first line of `bn2wn.tsv` is "# BabelNet 4.0.1 - SapienzaNLP - LICENSE: ...": each recipe passes it over, and it is not a row. `wn2lemma.tsv` and `wn2sense.tsv` have no licence line: their first line is a row. `README.txt` is read as ordinary text, as the source's `reads text` says: it is observed content, as [Attestations](../Semantics/Attestations.md#observations) describes, and attests nothing; the specification quoted above is its FORMAT section.
