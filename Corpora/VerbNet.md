# VerbNet

VerbNet attests class membership of a verb and the thematic roles and frames of that class.

## Value

| Attestation | What it means | Lands on | Value | Witness | Proof |
| --- | --- | --- | --- | --- | --- |
| class | VerbNet expands upon Levin's classification of shared syntactic alternations by making the relationships between syntax and semantics explicit. | the VNCLASS record | the class ID | VerbNet (University of Colorado) | [VerbNet Annotation Guidelines](https://verbs.colorado.edu/verb-index/VerbNet_Guidelines.pdf); `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd`; `/vault/Data/VerbNet/verbnet-master/README.md` |

## Format

| Record | Fields in order | What a record is | Proof |
| --- | --- | --- | --- |
| VNCLASS | MEMBERS, THEMROLES, FRAMES, SUBCLASSES; attribute ID | A verb class. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| MEMBER | attributes name, wn, grouping, fn_mapping, verbnet_key, features | A verb listed in a class or subclass. wn and fn_mapping are fields on the member. They are not a [Wordnets](Wordnets.md) or [FrameNet](FrameNet.md) attestation. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| THEMROLE | SELRESTRS; attribute type | A thematic role of a class. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| SELRESTR | attributes Value (+ or -), type; SELRESTRS may nest and may carry logic | A selectional restriction on a role or inside another restriction. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| FRAME | DESCRIPTION (descriptionNumber, primary, secondary, xtag), EXAMPLES/EXAMPLE, SYNTAX, SEMANTICS | A syntactic frame of a class, with examples and semantic predicates. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| SYNTAX | NP, ADV, ADJ, PREP, LEX, then VERB, then NP, ADV, ADJ, PREP, LEX | The syntactic pattern of a frame. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| SEMANTICS | PRED (bool, value) containing ARGS/ARG (type, value) | The semantic predicates of a frame. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
| VNSUBCLASS | MEMBERS, THEMROLES, FRAMES, SUBCLASSES; attribute ID | A subclass, with the same child elements as a class. | `/vault/Data/VerbNet/verbnet-master/verbnet3.4/vn_schema-3.xsd` |
