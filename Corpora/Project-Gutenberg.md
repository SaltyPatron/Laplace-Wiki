# Project Gutenberg

Project Gutenberg's texts are observed content and attest nothing.

## Format

| Record | Field | Order | Type | Specification |
| --- | --- | --- | --- | --- |
| PG metadata | PG.Id | 1 | ebook number | The ebook number. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | PG.Released | 2 | date | The PG release date in YYYY-MM-DD format. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | PG.Rights | 3 | enumeration | Either 'Public Domain' or 'Copyrighted'. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | PG.Title | 4 | text | A much shortened form of the title, used in the PG boilerplate lines that say the start and the end of the ebook. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | PG.Producer | 5, repeatable | one name | A personal name or organization that helped produce the text. One name per field. The field may be repeated. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | PG.Credits | 6 | text | A line acknowledging the source of the images or other stuff. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | DC.Creator | 7, repeatable | one name | Author. A personal name or organization that created the text. One name per field. The field may be repeated. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | DC.Title | 8 | text | The full title statement as found on the book's title page. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | DC.Language | 9, repeatable | 2- or 3-letter code | One code per field for each language used for a substantial portion of the text. The manual says the codes are indicative for the catalog and do not set the text language or the hyphenation rules. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | DC.Created | 10 | year | The year of original publication if known. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | MARCREL.edt | 11, repeatable | one name | Editor. One name per field. The field may be repeated. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | MARCREL.ill | 12, repeatable | one name | Illustrator. One name per field. The field may be repeated. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | MARCREL.trl | 13, repeatable | one name | Translator. One name per field. The field may be repeated. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | MARCREL.* | 14, repeatable | one name | Any other MARC relator code. The manual points to <http://www.loc.gov/marc/relators/relacode.html.> One name per field. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| PG metadata | coverpage | 15 | image path | A cover image for formats that support a cover page. The image is included in the upload and need not be in the text flow. The metadata directive is what `.. pgheader::` turns into the PG header. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
| body | text | after the generated header and before `.. pgfooter::` | text | `.. pgheader::` inserts the header generated from the metadata. `.. pgfooter::` inserts the footer and license. The body is the text between them. The manual defines no sense and no part of speech for that text. <https://www.gutenberg.org/cache/epub/181/pg181.txt> |
