## Format

| Record | Fields in order | What a record is | Proof |
| --- | --- | --- | --- |
| bibliographic record | Creator, Title, Alternate title, Note, Reading level, Original publication, Credits, Language, Category, LoC Class, Subject, Automated summaries, EBook-No., Release Date, Copyright Status, Downloads | The table on the eBook landing page. The page says it contains all information collected about the eBook and that not every item is present for every eBook. Format and Size are defined on the same help page, above the bibliographic record. | [Help on the Bibliographic Record](https://www.gutenberg.org/help/bibliographic_record.html) |
| plain text file | the bytes of the file; header labels, when present, are lines before the Project Gutenberg start marker | A text file in the drop. The bibliographic-record page defines the metadata fields. The file's body is the text. | [Help on the Bibliographic Record](https://www.gutenberg.org/help/bibliographic_record.html) |
